# Kaspeak SDK

**Kaspeak SDK** — это инструмент для быстрого и удобного создания полнофункциональных децентрализованных приложений на базе высокопроизводительной сети Kaspa. SDK берёт на себя все низкоуровневые задачи: формирование, отправку и приём сообщений, работу с транзакциями и криптографию. Вам остаётся сосредоточиться только на логике вашего приложения.

## Что вы можете делать с Kaspeak SDK

* Создавать и передавать любые текстовые или бинарные данные напрямую через транзакции сети Kaspa.
* Легко разрабатывать собственные типы сообщений с автоматической сериализацией и коллбеками.
* Использовать встроенные и проверенные криптографические методы для защиты данных и подтверждения авторства (ECDH, XChaCha20-Poly1305, Schnorr-подписи).
* Минимизировать расходы на транзакции благодаря компактной упаковке данных (CBOR) и эффективному сжатию (Zstandard).
* Поддерживать конфиденциальные диалоги при помощи уникальных криптографических идентификаторов.
* Запускать приложения одинаково просто как в браузере, так и на Node.js без дополнительной настройки.

## Основные преимущества Kaspeak SDK

* **Скорость и масштабируемость**: мгновенная доставка данных благодаря высокой пропускной способности сети Kaspa.
* **Минимальные комиссии**: за счёт эффективного кодирования данных.
* **Безопасность и конфиденциальность**: интегрированы надёжные криптографические схемы.
* **Простота интеграции**: единый удобный SDK для разных сред разработки.
* **Расширяемость и удобство**: возможность добавления собственных типов сообщений и регистрация обработчиков событий.

Kaspeak SDK идеально подходит для создания приватных и публичных чатов, игр и игровых сервисов, систем уведомлений и оповещений, сервисов обмена файлами и передачи данных, а также любых других децентрализованных приложений.
